# Dashboard 设计规范

以现有轻量灰白界面为基准。新页面和弹窗保持一致的信息层级、留白、控件与反馈，不为单个功能引入新的视觉体系。

## 品牌与常驻入口

- Logo 为 34 × 34px 黑底白线图标，圆角 8.5px，保留原椰子路径；品牌字标使用 Outfit 400、27px、1.15 行高，与 Logo 间距 7px。固定上移 1.5px，保留字形居中及轻微光学校正。采用紧凑单行，登录页与侧栏一致，不显示副标题或连接状态。
- 品牌图标距页面顶部与左侧等距：桌面项目页 18px、登录页 32px；窄屏项目页 16px、登录页 24px。窄屏品牌顶部对齐，避免右侧账号区域的高度改变其留白。
- 字体只包含品牌字符，使用固定字重 WOFF2 子集，随服务端嵌入，同源预加载与内容摘要长缓存，不请求外部字体服务。正文使用系统字体。
- 标签页 favicon 使用原版透明底椰子 SVG，不使用页面内的黑色圆角底板。用绝对资源路径，首页和项目深链接保持一致。
- 设置末尾保留“服务端版本 / Server version”便于核对。不把服务端版本当作本机客户端版本。
- 连接指引标题与入口统一为“连接本地文件夹 / Connect a local folder”。分享弹窗与加入成功提示复用该指引；未登录页底部保留一行文字入口。侧栏底部仅保留账号入口，不另设安装按钮，空状态不增加按钮。
- 登录页左侧使用浅灰 ASCII 字符涟漪：固定网格、多样字符与平滑字重，局部灰度保持克制。动画纯装饰，不提供额外交互或预览控件；登录后、页面后台与窄屏隐藏时停止绘制，减少动画偏好保留静态构图。视觉模块独立加载，资源或 Canvas 不可用时保留点阵背景及正常登录流程。

- 底部工具栏分两组：刷新、分享、设置；缩小、放大、适应画布。不单独保留工作目录、同步状态或问号帮助按钮；同步状态仅从右上角的处理中 / 异常通知进入，正常时隐藏，设置不保留备用入口。分享弹窗先呈现项目链接及复制按钮，再以分隔线和 24px 留白展示已连接目录及连接入口；两组独立加载和反馈错误。

## 弹窗与控件

继续使用现有原生 `dialog`、统一标题 / 关闭按钮和背景遮罩。标题与正文左侧对齐；桌面正文左右 24px，窄屏 16px。内容超高时仅正文滚动，关闭按钮保持可见。默认宽度 640px，设置 / 连接设备 480px，目录连接 620px，主页「＋」500px。

| 共用样式 / 组件 | 用途 |
|---|---|
| `dialog-stack` | 主要分组垂直间距 24px。 |
| `dialog-section` | 同一组标题、正文和辅助内容间距 12px。 |
| `dialog-card` | 有独立意义的问题卡片：20px 内边距，窄屏 16px；12px 圆角与柔和边框。 |
| `dialog-description` | 说明文字：13px / 22px，中性灰。 |
| `dialog-lead` | 主要结论或问题原因：14px / 24px。 |
| `dialogActions()` / `dialog-actions` | 操作区域统一右对齐、内容宽度、12px 间隔；按钮尺寸由 `button.mjs` / `button.css` 统一管理。窄屏允许换行。 |
| `commandBlock()` | 可选择的命令文本与 40px 图文复制按钮。长命令换行，不撑破弹窗。 |
| `disclosure()` | 统一折叠箭头、行高、键盘操作；技术细节默认折叠。 |

连接弹窗和主页左上角“+”共用 `mountProjectChoices()`。目录连接先显示“属于已有项目 / 通过分享链接加入项目 / 创建新项目”三个入口；主页“+”只显示加入和创建两个入口。加入表单的字段标签为“通过分享链接加入 / Join with a shared link”，占位为 `https://coconet.space/...`，不再提示输入项目 ID。选中后，大按钮向左收拢为紧凑导航，右侧显示一份表单；直接点击导航切换并保留已输入内容，不另设返回按钮。窄屏导航横排在上方，表单使用全宽；减少动画偏好直接切换。目录连接使用已有项目下拉选择，同名项目以 ID 区分；没有已加入项目时禁用该入口。同名创建仅作提示，不禁止创建。目录连接的内容区最小高度 220px，主页“+”为 156px，避免不必要留白。仅 CLI 连接入口显示“当前正在连接文件夹：路径”，路径无下划线；“选择其他文件夹”保留下划线，下一行左对齐。主页“+”和分享链接只处理项目成员关系。底部只保留必要错误反馈，不增加取消按钮；X / Esc 取消未提交的连接，提交中关闭仅收起界面，不撤回已提交请求。

打开分享链接时，未加入用户看到“你受邀加入一个协作项目”、项目名称及“加入后，可以查看项目协作图，了解同事的工作进展和共享会话。”，保留单个“加入项目”按钮。名称使用 16px / 24px、500 字重，直接排在正文上方，不加嵌套卡片。分享链接没有分享者身份，不把创建者标为邀请人。项目信息加载中或不可用时禁用加入，失败给出原因并可重试；关闭后的迟到结果不能覆盖其他弹窗。不重复显示创建入口或链接输入框。确认加入并加载看板后，在同一弹窗显示“已加入「项目名称」”及“如需同步自己的工作进展，可以连接本地文件夹。”按钮从左到右为黑底“好的”和白底“如何连接本地文件夹”：前者关闭弹窗，后者打开当前项目的连接指引，不再次加入或连接设备。主页“+”加入后复用该成功提示；网页创建项目成功后直接打开带该项目连接命令的本地文件夹指引，不显示加入成功页。CLI 目录连接中创建项目仍直接完成当前连接。创建或加入后已关闭弹窗时，不因迟到的看板请求再次打开指引。已有成员打开链接直接进入看板。长项目名称在统一标题内换行；加入失败可重试，关闭后的迟到响应不再打开提示。

弹窗主标题 20px / 28px、卡片标题 16px / 24px、普通分组标题 14px / 22px，字重 500。用留白和字号表达层级，不为每一行增加卡片。白色弹窗与直接内容区域最多两层底色，普通分组和折叠区域透明。浅蓝仅用于已有选中 / 启用语义。

按钮按操作语义统一分级，同一操作在不同弹窗使用相同样式：

| 级别 | 样式 | 适用操作 |
|---|---|---|
| 主要操作 `primary` | 黑底白字，悬停深灰。 | 登录、创建 / 加入项目、确认连接、连接目录、保存、复制会话指令 / 重试命令、重试暂停的任务。 |
| 危险操作 `danger` | 红底白字，悬停加深。 | 退出登录、退出项目及其最终确认。 |
| 次要操作（默认按钮） | 白底深色文字、柔和边框，悬停浅灰。 | 移除设备、复制项目链接、安装引导复制命令，以及取消、刷新、加载更多、查看同步状态和工作详情中的读取 / 继续入口。 |

操作按钮使用 `createButton(label, { glyph, size, className, onClick, type })`；既有静态登录按钮使用 `styleButton()`，切换语言用 `setButtonLabel()`，避免覆盖图标。不要在业务代码中另行拼接图标、改按钮内边距或最小高度。

| 尺寸 | 内容与规则 | 使用位置 |
|---|---|---|
| `regular`（默认） | 左图标 + 文字；40px 最小高度、13px / 20px 字体、10px 圆角、16px 图标、8px 间距。 | 所有弹窗动作，包括复制、移除设备、重试、加载更多；工作详情中的查看最新版本。 |
| `compact` | 纯文字；32px 最小高度、12px / 20px 字体、8px 圆角，不添加图标。 | 仅弹窗外的小型画布状态通知，不与弹窗内动作混排。 |
| `session` | 会话专用图文按钮；保留 40px 最小高度、12px 字体和现有网格布局。 | 读取、继续、收藏会话。 |

同一行文字时保持统一高度；长文本可自然换行，不能裁掉内容。卡片主按钮可以铺满所在卡片宽度，但高度与常规按钮一致，不使用独有的右箭头样式。关闭 / 新增 / 画布工具栏继续为纯图标控件；文字链接、侧栏导航、折叠项和 DAG / 收藏内容卡片保留各自布局。

每个独立操作组突出一个主要动作。设备列表的移除按钮、安装步骤的复制按钮采用白底；不要把导航、关闭、折叠或工具栏图标改成主要按钮。保留统一的禁用反馈与可见键盘焦点，黑底 / 红底按钮使用白色焦点线，白底按钮使用深色焦点线。

分享中的目录按“用户 · 设备”列出，路径默认隐藏，悬停查看，点击或键盘展开。界面统一使用“连接设备 / Connect device”“确认连接 / Confirm connection”“我的设备 / My devices”“移除设备 / Remove device”。连接不表示实时在线，移除设备撤销凭据但不删除本机文件；后台授权协议名称不变。

## 信息与状态

- 通知入口使用“查看同步状态 / View sync status”，弹窗标题使用“同步状态 / Sync status”。优先呈现一句结果或待处理数量；正常状态不附加继续工作等引导，不重复显示同义概况和计数。诊断命令、排查指引与同步版本默认折叠。网页没有设备实时状态；进展“处理中”描述同步结果尚待更新，不证明设备正在推理。空内容与已处理但无工作进展分别显示“暂无内容”“暂无工作进展”；可编辑节点与对话待办不代表处理故障。
- 界面使用短句，动作明确；协作空间统一称“项目 / Project”，设备上的目录称“本地文件夹 / Local folder”。连接指引不额外展示“连接到：项目名称”一行，默认只展示一条 `coconet connect` 命令，项目入口附带当前项目 ID，自部署附带 API 地址；未登录入口省略项目 ID。说明在目标文件夹打开终端，确认浏览器连接后重新打开 Agent。安装命令与 Hook 提示放入默认折叠的“首次使用？ / First time here?”，共享范围另设折叠项：历史不自动导入，继续旧会话可能带入此前内容，成员可读取会话与工具调用。复制按钮保持白底，关闭返回原入口。按当前产品文案约定，前端不显示模型用量说明；技术文档继续准确记录架构边界。
- 刷新图标仅在网页读取、校验和布局期间旋转并禁用，同时设置可访问的忙碌状态与双语名称。成功、失败、项目切换或退出登录后恢复，旧响应不能解除新请求的忙碌状态；待处理会话不让按钮持续旋转。遵循减少动画偏好。失败保留内容，刷新保留已展开详情和滚动位置。重试与复制使用对应区域的操作按钮。
- 弹窗打开时收起画布的持续处理通知，关闭后恢复；复制等短暂反馈继续可见，窄屏放在底部以避开标题和关闭按钮。
- 页面隐藏时暂停更新订阅，恢复可见后重新连接。后台处理使用新检查点发布事件驱动刷新，中间提交不刷新；不引入周期性 DAG 拉取。
- 通知文本允许正常换行，操作按钮独立右对齐；窄屏放在 Library 入口下方，使用画布可用宽度，避免挤成单字符或推到视口之外。
- 所有界面文案、悬停说明、按钮和错误反馈支持中英文。受控系统错误解释可以本地化；项目名、会话内容、错误码及自定义来源文本保持原文。命令参数必须使用既有安全引用逻辑。

## 节点详情

节点说明按“进展与结论 / Progress & conclusions”和“关键思路 / Key approach”呈现；只展示非空字段。段间 24px，标题 13px / 22px、字重 500，标题与正文间隔 8px；正文 14px / 24px，保留换行并允许长词折行。使用纯文本，不解析 Markdown 或 HTML，不为说明另加卡片。旧节点只展示已有的进展与结论。

## 修改后的验收

本人节点的星标直接收藏 / 取消收藏，与 Agent 工具共用 Library 状态，不再打开指令弹窗。提交时禁用，成功后按发布图更新，失败可重试。收藏固定来源并封存节点，不等于完成任务；取消收藏不重新打开仍有效的节点。

检查桌面及 390px 窄屏的中英文布局，必要时补查 320px；包括长命令 / 错误码、空数据、加载、失败和恢复。确认正文无横向溢出，按钮有明确名称，Tab / Esc 正常，关闭后焦点回到入口，复制失败可以手选文本。浏览器验证使用生产 handler 和隔离合成数据，截图辅助人工复核；真实会话保持不变。
