# Security reports

Please do not put credentials, private conversations or exploitable production
details in a public issue. Use the repository's **Security → Report a vulnerability**
entry when available, or email the maintainer at <xfey99@gmail.com>.

Include the affected version, deployment type, impact and a minimal synthetic
reproduction. Redact tokens, cookies, signed object URLs and personal paths.

The latest release is the maintenance target; no separate long-term support branch
is promised. See [data sharing](docs/data-sharing.md) for the current trust model.

报告安全问题时请使用私密渠道，不要在公开 Issue 附上令牌、真实会话或生产环境细节。
也可以发送邮件至 <xfey99@gmail.com>。
